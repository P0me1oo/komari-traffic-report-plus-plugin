# 流量定期报告

通过 `public:queryMetrics` 查询 `traffic.up` 和 `traffic.down`，按选择的节点发送日报、周报和月报。插件不读取数据库，也不复用服务端流量日报实现。

配置页支持简体中文、繁体中文和 English。

## 配置

- 为全部节点启用：开启后忽略节点选择，始终统计全部节点。
- 选择节点：使用 `nodes` 类型选择要统计的节点；未开启“为全部节点启用”时生效。
- 节点排序：面板顺序（与管理面板一致）或流量排序（按周期内总流量从高到低，无数据的节点排在最后）。
- 显示上下行明细：开启时在节点行和合计行中显示上传、下载分项；关闭后仅显示总流量。
- 显示峰值带宽：开启时在节点行和合计行中显示统计周期内的上下行峰值速率，数据来自 `net.out.rate` 和 `net.in.rate`。
- 通知模板：留空使用系统通知模板；填写后由插件替换以下占位符：
  - `{{period}}`：流量日报、流量周报或流量月报
  - `{{period_short}}`：周期简写（日报为日期，周报为日期区间，月报为年月）
  - `{{start}}` / `{{end}}`：报告周期的本地时间边界
  - `{{message}}`：默认完整报告
  - `{{nodes}}`：节点明细
  - `{{total}}` / `{{total_up}}` / `{{total_down}}`：合计流量
  - `{{node_count}}`：节点数量
  - `{{event}}` / `{{emoji}}` / `{{time}}`：通知事件字段

报告为中文纯文本，第一行是标题和周期，第二行是合计（含分项和峰值），其后按排序方式列出各节点：

```
流量日报 · 2026-09-02
合计：5.90 GB（↑ 1.24 GB / ↓ 4.66 GB，峰值 ↑ 3.20 MB/s ↓ 8.10 MB/s）

香港节点：5.79 GB（↑ 1.23 GB / ↓ 4.56 GB，峰值 ↑ 3.20 MB/s ↓ 8.10 MB/s）
东京节点：112.00 MB（↑ 12.00 MB / ↓ 100.00 MB，峰值 ↑ 812.00 KB/s ↓ 1.20 MB/s）
美国节点：暂无数据
```

没有采样记录的节点会显示为“暂无数据”，不会显示为 `0 B`。
- 日报：默认每天早上 9 点。
- 周报：默认关闭，默认每周一早上 9 点。
- 月报：默认关闭，默认每月 1 号早上 9 点。

定时计划支持 5 字段、6 字段 cron 和 `@every` 表达式；插件会自动修正 `@every1m` 这种紧凑写法。保存配置后服务端会自动重新加载插件，新的计划会立即生效。

## 数据保留时间

请在数据库中将 `traffic.up`、`traffic.down` 以及 `net.out.rate`、`net.in.rate` 的保存时间调整到足够长：日报至少 1 天，周报至少 7 天，月报至少 31 天。保存时间过短会导致报告漏数据或峰值偏低。

```sh
npm install

npm run dev
```
